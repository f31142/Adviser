# Adviser 요구사항

이 문서는 이 대화에서 확정된 요구사항을 보존한 것입니다. 실행 가능한 소스 코드의 이전 완료를 의미하지 않습니다.

## 서비스

사촌이 운영하는 유료 서류 첨삭·작성 서비스를 고객 신청, 관리자 검토, 결제, 결과 전달, 피드백까지 관리합니다. 여기서 “서류”는 자기소개서 등 제출 문서를 통칭합니다.

| 서비스 | 신청 자료 |
| --- | --- |
| 기존 서류 첨삭 | 작성한 서류 첨부, 제출 기관, 비고, 공통 설문 |
| 새 서류 작성 | 제출 기관, 비고, 공통 설문. 기존 서류 첨부는 선택 |

두 서비스 모두 초기 가격은 100,000원입니다. 관리자가 서비스별 가격을 수정하며, 기존 신청의 금액은 신청 당시 기록을 유지합니다.

## 신청과 결제 순서

1. 고객이 이메일·비밀번호로 가입하고 로그인합니다.
2. 서비스를 선택하고 설문을 작성합니다. 첨삭 서비스는 원본 서류를 첨부합니다.
3. 고객이 신청서를 제출합니다.
4. 관리자가 신청 내용과 서류를 검토하고 승인하거나 보완을 요청합니다.
5. 보완 요청을 받은 고객은 신청서를 수정해 다시 제출합니다.
6. 승인된 신청에 대해 고객이 결제합니다.
7. 결제가 확인되면 관리자가 첨삭 또는 작성을 진행합니다.
8. 관리자와 고객이 신청별 채팅으로 피드백을 주고받습니다.
9. 관리자가 결과물을 전달하고, 고객이 검토하거나 정해진 범위에서 수정을 요청합니다.
10. 작업을 완료합니다.

이 순서는 기존의 결제 선행 방식에서 변경된 최종 요구사항입니다. 관리자 승인 전 결제 요청과 결제 확인을 서버에서도 제한해야 합니다.

## 공통 설문

- 제출 기관
- 지원 직무
- 학력
- 경력
- 주요 경험
- 작성 문항과 각 문항의 글자 수
- 희망 마감일
- 비고 및 요청사항

기존 구현 기록에는 신청 동의와 필요한 항목의 서버 검증이 포함됩니다. 구체적인 필수 입력 조건은 원본 코드 회수 후 대조합니다.

## 고객 계정과 권한

- 이메일·비밀번호로만 회원가입합니다. 간편로그인은 제외합니다.
- 자신의 신청 목록, 진행 상태, 결제 정보, 채팅, 첨부 파일과 결과물을 확인합니다.
- 다른 고객의 신청·채팅·파일에는 접근할 수 없어야 합니다.
- 로그인한 상태에서 비밀번호를 변경하고 로그아웃할 수 있어야 합니다.
- 이메일 인증과 비밀번호 찾기 메일 발송은 기존 구현 기록상 미구현입니다.

## 관리자 계정과 권한

- 관리자 로그인 ID는 ADMIN입니다.
- 관리자 비밀번호와 해시는 GitHub 문서나 코드에 기록하지 않습니다.
- 모든 신청을 확인하고 조건별로 찾을 수 있습니다.
- 신청을 승인하거나 보완을 요청합니다.
- 서비스별 가격과 운영 설정을 변경합니다.
- 입금 확인, 작업 진행 상태 변경, 결과물 전달, 고객 피드백 응대를 수행합니다.
- 취소와 환불 처리 상태를 관리합니다.

기존 승인 흐름에는 “보완 요청”이 구현된 것으로 기록되어 있습니다. 영구 반려의 구체적인 처리 방식은 원본 코드에서 확인해야 합니다.

## 결제

사용자는 카드·간편결제 등 결제대행사를 통한 결제와 계좌이체를 함께 제공하기를 원합니다.

- 계좌이체: 관리자가 입금 계좌를 설정하고 실제 입금을 확인한 뒤 결제 완료로 처리합니다.
- 결제대행사 결제: 가맹점 연동과 실제 결제 검증이 필요합니다. 기존 구현에서는 준비 중으로 표시하며 실제 결제가 연결된 것으로 표현하지 않습니다.
- 환불: 기존 구현 기록상 수동 환불 후 관리자가 처리 상태를 기록하는 방식입니다.
- 금액은 서버에서 서비스 설정을 기준으로 확정하며, 고객이 임의로 변경한 금액을 신뢰하지 않습니다.

## 피드백과 운영 기능

- 신청별 고객–관리자 채팅
- 원본 첨부와 관리자 결과물 전달
- 수정 요청 횟수 관리
- 진행 상태 및 사이트 내 알림
- 취소 요청과 환불 상태 관리
- 종료된 작업의 파일 정리

이메일·문자 알림은 기존 구현 기록상 연결되지 않았습니다.

## 진행 중인 요청

기존 계정 정보를 초기화한 뒤 관리자 승인 후 결제하는 수정본을 게시해야 합니다. 계정 초기화, 원본 코드 이전, 수정본 게시 모두 아직 완료되지 않았습니다. GitHub 이전 대상은 소스·설정 예시·스키마·문서이며, 실제 고객 데이터와 비밀값은 제외합니다.
