## 데이터와 비밀값

이 저장소에는 실제 고객 계정, 비밀번호 해시, 세션, 신청서, 채팅, 업로드 파일, 인증 토큰을 저장하지 않습니다. 관리자 비밀번호는 소스에 직접 넣지 않고 서버의 비밀 설정으로 관리합니다.

사이트 계정은 운영 데이터베이스에 저장되므로, GitHub 파일을 수정하거나 사이트를 재게시하는 것만으로 초기화되지 않습니다.

## 현재 목표

1. 기존 Sites 원본 전체를 회수하고 비밀값과 고객 데이터가 없는지 확인합니다.
2. 원본 소스·DB 스키마·의존성 잠금 파일·정적 자산·기존 검증 코드를 이 저장소로 옮깁니다.
3. 원본의 관리자 인증과 데이터 관계를 확인한 뒤 계정 초기화 작업을 구현합니다.
4. 검증 후 운영 계정 초기화를 실행하고, 관리자 승인 후 결제하는 수정본을 게시합니다.

위 항목들은 아직 완료되지 않았습니다.
