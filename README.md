# Adviser

유료 서류 첨삭·초안 작성 서비스를 위한 한국어 웹 애플리케이션입니다. **GitHub `f31142/Adviser`의 `main`이 원본입니다.** React/TypeScript 화면, Node.js 24 서버, SQLite 데이터베이스, 비공개 파일 저장소를 포함합니다. ChatGPT Sites 계정이나 호스팅 없이 실행합니다.

## 제공하는 기능

- 이메일·비밀번호 회원가입(8~16자·특수문자 포함), 단일 로그인 화면, 역할별 메뉴, 로그아웃과 비밀번호 변경
- 기존 서류 첨삭 / 초안 작성 지원, 각 100,000원에서 시작하는 관리자 가격 설정
- 설문·파일 제출 → 관리자 검토·보완 요청·승인/반려 → 결제 → 작업 → 고객 검토·수정 → 관리자 작업 완료 → 고객 완료 확정
- 고객별 마이페이지, 관리자 전체 작업 검색·상태 필터
- 관리자 회원 검색·계정 삭제, 삭제된 고객의 세션 종료 및 기존 작업 기록 보관
- 작업별 실시간 채팅과 사이트 내 알림, 비공개 원본·결과물 다운로드, 새로고침 시 현재 화면 복원
- 계좌이체 확인, 선택적 토스페이먼츠 카드·간편결제 연동
- 수정 횟수 설정, 취소 요청, 환불 상태 기록, 종료된 작업의 파일 삭제
- 관리자 비밀번호 복구 및 고객 데이터 초기화 CLI

**이 저장소에 코드를 올리는 것만으로 공개 사이트가 생기지는 않습니다.** 실제 접속 주소에는 서버와 영구 저장 공간이 필요합니다. GitHub Pages만으로는 로그인·채팅·DB 기능을 실행할 수 없습니다. [외부 배포 안내](docs/deployment.md)를 확인하세요.

## 바로 실행하기

Node.js 24를 설치한 후:

```sh
git clone https://github.com/f31142/Adviser.git
cd Adviser
npm ci
cp .env.example .env
```

`.env`의 `ADMIN_PASSWORD`에 초기 관리자 비밀번호를 직접 설정합니다. 실제 비밀번호는 Git에 넣지 않습니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:3000`에 접속합니다. 일반 로그인 화면에 `ADMIN`과 설정한 비밀번호를 입력하면 관리자로 로그인합니다. 초기 비밀번호는 DB에 관리자 계정이 없을 때만 적용되며, 기존 계정이 보존된 재배포에서는 비밀번호를 덮어쓰지 않습니다.

```sh
npm run build
npm start
```

운영 서버도 같은 명령으로 실행합니다. 최초 시작 시 `db/migrations`를 순서대로 적용합니다. `DATA_DIR` 아래에 DB와 첨부파일이 저장되므로 이 디렉터리를 영구 디스크에 연결해야 합니다.

## 검증

```sh
npm run build
npm test
npm audit --audit-level=high
```

테스트는 임시 DB·첨부 디렉터리와 가짜 결제 응답을 사용합니다. 실제 결제나 운영 데이터 변경은 수행하지 않습니다. 실제 HTTP 서버, 계정 복구·초기화, 데이터 재시작 보존, 접근 권한, 승인 전 결제 차단, 중복 승인, 금액 변조, 결제 응답 검증과 업무 흐름을 확인합니다. GitHub Actions에서 빌드·테스트·의존성 검사·Docker 빌드 및 기동을 실행합니다.

## 운영 전 연결할 항목

- **호스팅**: Render 연결 또는 Docker를 실행할 서버. `render.yaml`은 단일 서버와 영구 디스크를 정의합니다. 유료 리소스이므로 생성 전 비용을 확인하세요.
- **관리자**: 초기 비밀번호는 호스팅의 비밀 환경변수로 설정합니다.
- **계좌이체**: 관리자 운영 설정에서 은행·계좌번호·예금주를 입력해야 입금 확인 요청이 활성화됩니다.
- **카드·간편결제**: `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` 두 값을 넣어야 활성화됩니다. 테스트 키는 화면에 테스트 결제로 표시합니다. 아직 가맹점 키를 연결하거나 실제 승인·환불을 검증한 상태는 아닙니다.
- **안내 문구**: 실제 운영할 취소·환불·자료 보관 조건을 관리자 화면에 입력합니다.

이메일 소유 확인, 비밀번호 재설정 메일, 문자/메일 알림은 연결하지 않았습니다. 비밀번호를 잊은 경우 관리자가 본인 확인 후 복구 CLI로 처리합니다. 온라인 환불은 결제업체 관리자에서 처리한 뒤 사이트의 **온라인 결제 상태 확인**으로 전액 취소를 반영합니다. 부분 환불은 수동 정산이 필요합니다.
